Working with an exposure

  1. Choose an SDSS exposure or import a two-dimensional image. FITS file rows are shown in array order.
  2. Click the image to read a point, drag a box to scope tools, or drag a line to measure along it. Polygon mode adds vertices one click at a time.
  3. Use Measure for star catalogs, aperture flux, profiles and derived exposures. Select a marked source before measuring its aperture.
  4. Save an observation or export the inspection box from Frame. Scientific output preserves source values and missing pixels.

The Display tab controls appearance. Changing the stretch leaves original intensity and measurements unchanged.
